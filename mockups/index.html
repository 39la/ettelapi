URL / routing candidates

Same content, different URL shapes. All accept 3- and 6-digit hex.

Shape Example Trade-off
A Hyphen path + extension /ff3b30-f94144-577590.svg Short, paste-safe, no escaping. Canonical pick.
B Slash segments /p/ff3b30/f94144/577590.svg Robust parsing, but long and noisy.
C Comma path /ff3b30,f94144,577590.svg Prettiest, but clients often escape , to %2C.
D Query only /palette?c=ff3b30,f94144&format=svg Flexible, but the URL doesn't read as an image.
E Hybrid (A + aliases) /ff3b30-f94144.svg Canonical A, 301 the others. HTML at the extension-less URL.
Recommendation: canonical /{hex-hex-hex}.svg, HTML at the same path without the extension, and ?layout=, ?w=, ?theme= for options. Serve SVG by default; add .png via resvg-wasm for og:image, since most crawlers still refuse SVG.
